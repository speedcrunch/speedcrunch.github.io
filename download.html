What's new in 1.1

  • Functions
  • Constants and units
  • Input
  • Results
  • Sessions and settings
  • Appearance and panels
  • Keypad
  • Other improvements

Functions

  • Add root(n; x) for nth roots, including negative values and quantities with units. For example, root(5; -32) returns -2.
  • Fix factorials in user-defined functions, such as f(n) = n!.

Constants and units

  • Search constants by name or unit with Ctrl+Space. Select a result with the arrow keys and insert it with Enter, Tab, or a click.
  • Improve searching and keyboard selection in the Constants panel.
  • Correct the units of the muon, proton, and neutron energy equivalents.
  • Allow powers of grouped quantities, such as (2[m])^2.
  • Correct results shown in J/m² and J/m³ when using prefixed units.

Input

  • Fix undo and redo, and copy and paste.
  • Fix clipped text and excess space in wrapped input with different fonts.
  • Fix crashes when typing operators in long, wrapped expressions.
  • Restore digit grouping while typing, following the selected number format.
  • Add an option to turn off automatic input adjustments, such as operator replacements and closing brackets.
  • Add optional Enter-to-accept autocomplete and Escape-to-clear behavior.
  • Add an option to use a steady cursor instead of a blinking one.
  • Preserve comments as written and prevent them from affecting result formatting.
  • Improve recalling expressions from history and focus the editor after startup.
  • Remove the empty-history hint.

Results

  • Restore free copying.
  • Copy a whole calculation, including all displayed result formats, either across multiple lines or as a single line.
  • Add optional removal of trailing decimal zeroes.
  • Simplify live previews to show just the results.
  • Keep live result previews above the editor when recalling long expressions from history.
  • Avoid unnecessary extra simplification lines.
  • Restore the F2-F5 and F7-F10 notation shortcuts.

Sessions and settings

  • Add private tabs that discard their contents when closed and are not restored on the next launch. Use Ctrl+Shift+N (Cmd+Shift+N on macOS) to open one.
  • Allow switching between private and saved sessions, and optionally open a private tab at startup.
  • Add Reset All Settings..., keeping sessions, history, and user definitions.
  • Fix global user definitions missing from restored sessions.
  • Make session renaming, cloning, closed-tab recovery, and pane controls easier to find in the menus. Cloning also copies unfinished input.
  • Organize the result context menu into Copy, Remove, Split, and Session groups.
  • Move Number Format... directly under Settings and simplify the result and appearance menus.
  • Apply font changes across all windows and fix font selection on macOS 27 and later.
  • Fix commands acting on the wrong window when used from a floating panel.

Appearance and panels

  • Add separate system and SpeedCrunch theme choices for menus, panels, and the status bar.
  • Add a compact Classic layout for input and results. Modern remains the default.
  • Improve text contrast, menu readability, and panel button visibility.
  • Match menu icons to the theme and dim disabled menu items and shortcuts.
  • Tidy panel spacing, borders, and rounded corners.
  • Keep side panels at full height and remember table column order.
  • Preserve floating panel positions and visibility across restarts, and prevent floating panels from being grouped unexpectedly.

Keypad

  • Add a compact Classic keypad appearance and 50% zoom.
  • Restore Zoom in the keypad's right-click menu and fix inconsistent sizing when changing zoom levels.
  • Update scientific layouts with nth-root, square, and argument-separator buttons, and group related operations together.
  • Replace the obsolete lg button with log10.

Other improvements

  • Reduce startup delays when restoring sessions, history, and panels.
  • Make update checks more responsive and prevent them from delaying window closure.
  • Add Help > App Diagnostics with a report that can be copied when asking for help. Show operating system details in About SpeedCrunch.
  • Fix a crash when closing windows with certain panels open.
  • Add portable macOS ZIP packages that keep settings and sessions beside the app in a SpeedCrunch-data folder.
  • Set the default macOS minimum version to 14.4 on Apple Silicon.

What's new in 1.0

  • Workspace and history
  • Expressions and editing
  • Results and formatting
  • New functions
  • Units
  • Appearance and settings

Workspace and history

  • Work in tabs and split panes to keep several calculations open side by side.
  • Save calculation history between launches and set a history size limit.
  • Load your own functions and variables at startup.
  • Choose a keypad preset or build a custom keypad.
  • Show or hide the main menu. The result display now has a right-click context menu with an entry for the main menu.
  • Re-edit an earlier expression and recalculate all the expressions below it.
  • Check for updates from within the app.

Expressions and editing

  • Use lists and matrices in expressions.
  • See the interpreted expression alongside the result, with implicit multiplication made explicit.
  • Write integer powers with superscript digits.
  • Use √, ∛, Σ (summation), and π as aliases. The ~ operator is an alias for not().
  • More symbol aliases are accepted for addition, subtraction, multiplication, and division.
  • Autocomplete suggestions now show category icons.
  • Pasted numbers are automatically formatted to match the global Number Format setting.
  • Insert constants and formula book entries with their units included.

Results and formatting

  • Show a calculation in several result formats at once. Number-format choices include Indian 3-2-2 digit grouping.
  • Show rational results as fractions, or use sexagesimal notation for angles and time.
  • Show angles as multiples of pi in radian mode or through an explicit conversion.
  • Choose how complex numbers are displayed, with polar forms and options for the imaginary unit.
  • Set a custom precision with the Custom... option.
  • Choose from five rounding modes.
  • Changing the primary result format updates only the last expression. Earlier history entries keep their formatting.

New functions

  • Integer arithmetic: powmod for modular exponentiation, emod for Euclidean modulo, lcm for least common multiples, and popcount for counting set bits.
  • Number formatting: binpad, octpad, and hexpad for padded binary, octal, and hexadecimal output. Use sci and eng for scientific and engineering notation.
  • Random numbers: rand and randint generate random decimals and integers.
  • Dates and time: datetime and epoch convert between date/time values and Unix timestamps.
  • Summation: sigma, also written as Σ.
  • Complex numbers: conj for complex conjugates and cis for constructing a complex number from an angle. Choose rectangular, exponential, or phasor output with rectform, expform, and phasorform.
  • IEEE 754: ieee754_round_* rounds to a floating-point format, and ieee754_*_residual(x) returns the rounding residual. Both families support half, float, double, and quad.
  • Chemistry: molmass, mass, and molarity for molar mass, mass from an amount of substance, and solution molarity.
  • Linear algebra and data: List and matrix support with cols, corrp, corrs, covp, covs, cross, det, dot, flatten, inv, norm, rank, rows, shape, trace, and transpose.
  • Statistics: stdevp, stdevs, varp, vars, and mad, with list and matrix support.

Units

Use square brackets to identify units explicitly in expressions, such as [m] or [s]. New units and aliases include:

  • Angles: gradian (gon), turn (tr, pla), revolution (rev), degree (°), arcmin (′), and arcsec (″).
  • Time: Julian century (cy_jul).
  • Area and mass: hectare and tonne.
  • Speed: kph and mph.
  • Energy: quad, equal to 1015 [Btu].

Appearance and settings

  • Choose from more built-in themes or create a custom theme.
  • Interface scaling now applies to the expression editor too.
